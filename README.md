### Now

**🎙️ Research: voices that reach**<br>
Comparing **LLM-enhanced text-to-speech** pipelines for **multilingual disaster communication in Nepal**: turning official flood and landslide alerts into clear, trustworthy voice messages for radio, phone and loudspeakers, in Nepali and local languages. My focus is **evaluation and safety**: testing for intelligibility, comprehension and factual faithfulness. *(in progress)*

**🧪 At work: Fractional QA Manager**
- E2E automation with **Playwright** (web) and **Appium** (mobile) for a multivendor e-commerce suite
- **AI-assisted testing**, API checks (**Postman · REST Assured**) and **JMeter** performance baselines
- Risk-based release governance for an **Engineering Valuation ERP**, across Nepal & Central Europe time zones

**🔬 In public**
- [**Sachet Eval**](https://github.com/sanjaygdrrad/sachet-eval) (सचेत, *alert*): open evaluation harness for AI-generated disaster alerts in Nepal. It checks that rewrites (SMS, radio scripts, translations, AI output) keep every level, time, place and instruction, and that nothing is invented or flipped ("above" never becomes "below"). Tested on real DHM and NDRRMA alerts. **[→ Try it in your browser](https://sanjaygdrrad.github.io/sachet-eval/)** [![CI](https://github.com/sanjaygdrrad/sachet-eval/actions/workflows/ci.yml/badge.svg)](https://github.com/sanjaygdrrad/sachet-eval)
- **Offline alert box**: an edge device that turns official bulletins into local-language voice alerts with no internet, for radio and loudspeakers *(prototype planned)*
- [**sanzay.com.np test suite**](https://github.com/sanjaygdrrad/sanzay-site-tests): 72 Playwright tests (desktop + phone) run **daily against the live site**: E2E, regression, accessibility and a performance budget. [![Live site tests](https://github.com/sanjaygdrrad/sanzay-site-tests/actions/workflows/live-tests.yml/badge.svg)](https://sanjaygdrrad.github.io/sanzay-site-tests/)
